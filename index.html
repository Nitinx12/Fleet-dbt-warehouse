Fleet dbt Warehouse

MySQL fleet_registry and MongoDB fleet_operations land in Postgres bronze through watermarked, contract-checked ingestion. dbt builds silver, gold and marts; approved non-PII marts sync to Databricks for BI. Airflow schedules the run, while control.* and audit.* keep the evidence.

Overview

One governed path from source to dashboard

Every boundary has one writer, a versioned contract and a check that fails the run when it drifts.

01

Contracted ingestion

Twelve YAML contracts define columns, types, keys, freshness and expected counts. Python extracts with a watermark and lookback, then lands immutable rows in bronze.

02

dbt owns transformation

Silver cleans and dedupes one model per source. Gold builds the conformed star schema, and marts denormalise it into guarded, ratio-safe BI grains. No transformation lives in Python.

03

Governed serving

Five approved, non-PII marts are published to Databricks. The driver scorecard stays in Postgres because it carries a driver display name.

04

Observable runs

Batches, watermarks, task outcomes, dbt results and reconciliation are stored in control.* and audit.*; failures emit a database notification.

Architecture

Strict funnel, explicit ownership

Airflow schedules scripts. Python moves data. dbt transforms it. The publisher only copies approved marts.

Data layers

What lives where, and who writes it

Cross-layer writes are deliberately blocked so replay and incident triage stay deterministic.

Layer Models / tables Written by Responsibility
bronze 12 landed tables ingestion / fixture loader Immutable record of what arrived, with _ingested_at.
silver 12 models dbt One model per source: rename, cast, dedupe, normalise flags, route rejects.
gold 13 models dbt Seven SCD1 dimensions, dim_date and six incremental facts.
marts 7 models dbt Six BI grains plus assert_marts_reconcile_to_facts.
Databricks copy 5 approved marts publisher Read-only Delta copy for BI; the driver scorecard is excluded.
Quality & governance

Fail fast, keep evidence, protect PII

A failed contract or data test blocks the run. Only transient connection failures are retried.

383

dbt tests: 348 error severity and 35 warn severity.

104

Collected Python and Airflow test cases.

12

Source contracts checked by make contracts-check.

7 + 1

CI jobs plus a full-history Gitleaks workflow.

  • Licence numbers are hashed in staging; the raw value stops there.
  • Dates of birth become age_band and never reach a mart.
  • Fuel card numbers are masked to the last four digits in staging.
  • Incident descriptions stay in Postgres bronze and out of gold marts.
Runbook

Start with the zero-credential demo

make help is the authoritative command list. Production targets require explicit confirmation and approval.

Local checks 
cp .env.example .env
make install
make check-tools
make env-check
make verify
make contracts-check
Fixture demo in fleet_dev 
make demo
Layer-by-layer build 
make dbt-silver ENV=dev && make dbt-silver-tests ENV=dev
make dbt-gold ENV=dev && make dbt-gold-tests ENV=dev
make dbt-marts ENV=dev && make dbt-marts-tests ENV=dev
make publish-marts ENV=dev

Airflow is started with make airflow-up; the UI is at localhost:8080.
